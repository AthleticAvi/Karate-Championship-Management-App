## [differs] What differs

- Branch type: `bug`.
- Reproduce it before changing anything.
- Write a failing test first. It proves the bug, and later proves the fix.
- Find the cause and fix that, not the symptom.
- Keep the fix small. Raise any refactoring with the owner.
