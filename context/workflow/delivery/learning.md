# Learning

Applies when: answering a question, understanding something, read-only work
Status: enforced

## Index

- [find] Finding the answer
- [answer] Answering

## [find] Finding the answer

1. Use the router to find the domain README that covers the question.
2. Grep the workflow catalogue for the topic, and read only the matching sections.
3. Read the code last, starting from the file the README points to.
4. Stop reading once the question is answered.

Do not read execution workflows. They say how to deliver, not how things work.

## [answer] Answering

- Say what is verified and what is inferred.
- Point to the file and line behind each claim.
- If context was hard to find, say so, and suggest where it belongs.
