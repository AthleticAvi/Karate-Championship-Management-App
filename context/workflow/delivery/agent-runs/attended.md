# Attended mode

Applies when: attended mode, owner present, presenting a plan, raising decisions, showing review findings
Status: enforced

## Index

- [plan] Plan
- [decisions] Decisions
- [findings] Review findings
- [progress] Progress

## [plan] Plan

Present the plan and wait for sign-off before executing. Challenge it first only if the owner
asks or `delivery/planning.md` calls for it.

## [decisions] Decisions

Raise decisions with a recommendation. Never decide scope or architecture alone.

## [findings] Review findings

Show every finding with a recommendation, then wait. Do not start on any of them until the
owner has seen them. Fix the ones the owner agrees.

## [progress] Progress

Report what changed and what needs a decision. Keep it short.
